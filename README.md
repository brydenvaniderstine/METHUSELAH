# METHUSELAH

Biometric data sovereignty platform. Five isolated layers — nothing bleeds between them.

```
METHUSELAH/
├── web/          ← React PWA (methuselah.ca). Imports from engine/ only.
├── api/          ← Vercel serverless functions (gen3-bridge, auth, glucose, vector-history,
│                    oura). Root-level permanently, not pending migration — Vercel requires
│                    /api at the project root, separate from web/'s own build output.
├── pipeline/     ← BLE RE work: pull scripts, decoders, raw data, findings.
│   ├── tools/
│   ├── decoders/
│   └── data/
│       ├── raw_pulls/
│       └── findings/
├── parsers/      ← One parser per lab/device source. All expose the same output dict.
│   ├── lifelabs/
│   ├── siphox/
│   └── insidetracker/
├── engine/       ← Thresholds, scoring, commands, cross-vector logic. The only thing web/ imports.
└── firmware/     ← XIAO ESP32S3 PlatformIO BLE bridge project.
```

This is the actual current structure, verified 2026-08-11 (`ls` at repo root) — not a target
still being migrated toward. The section below this used to describe an in-progress migration
("existing code lives at the repo root, pending move into the skeleton above") that had, in
fact, already finished; `src/`, `public/`, and `tools/` no longer exist at the root at all.

## Layer rules (enforced by README in each directory)
1. `web/` imports from `engine/` only — never from `pipeline/`, `parsers/`, or `firmware/`.
2. Each decoder in `pipeline/decoders/` is self-contained — shared utilities only in `pipeline/decoders/utils.py`.
3. Every parser in `parsers/` exposes the same output interface — a standard biomarker dict — so `engine/` is source-agnostic.

## Known cruft at the repo root (not part of the active structure, not yet cleaned up)
Two leftovers from before the migration above, confirmed still present 2026-08-11:
- `data/` — 832KB, 40 files, all dated 2026-06-19 through 2026-07-01 (pre-reorg). The active
  pipeline reads/writes `pipeline/data/` instead; this copy is orphaned, not a live duplicate.
- `build/` — 1.1MB, a committed `create-react-app` build output from back when the app built
  directly at the repo root (last touched by a real commit, 2026-07-07) — predates the `web/`
  reorg and is stale relative to it. Committed build artifacts generally shouldn't be tracked
  in git at all (they're regenerated by `npm run build`, not hand-edited).
Neither has been removed — that's a real decision (rewrites visible repo history/state), not a
docs fix, so it's flagged here rather than done unilaterally.
